**Stop and pause marks, the status history and the cluster mirror on the lease document** (agbossjs/agboss#1341, #1321e): `agboss_execution_leases` keeps `stopRequestedAt` / `stopMode`, `isExternallyPaused` with its reason and mode, and `fencedThroughToken`; `requestStop`, `stopOf`, `requestPause`, `unpause`, `pauseOf` and `markedOf` (one read) are on the document. Every mark is ONE update pipeline the server runs on the document as it is, upserting it, and monotone in the update itself — no value is read by the client and written back: a stop's and a pause's mode only escalate (`$cond`: `immediate` stays `immediate` whichever of two concurrent requests arrives last), `fencedThroughToken` only rises (`$max`) and is never cleared, `cancelRequestedAt` is never unset, `stopRequestedAt` is set only when absent. A mark that carries a thread's status entry runs in ONE transaction with its `agboss_thread_status_transitions` document (the record store's `append`, `complete` and `completeIfStatus` write theirs in the transaction of the status change; `statusHistory`, `forgetStatusHistory`); a standalone `mongod` without transactions fails closed at start. The fenced-effect and outbound-call checks read the tree's ROOT document — also for a child's key — and refuse with `ExecutionPauseFencedError`, `ExecutionStopFencedError` or `ExecutionCancelFencedError`. `syncClusterLease`, `endClusterLease` and `mirroredLeaseOf` mirror a cluster's lease in one atomic upsert that keeps the marks and never lowers the token (`Behind` / `Retired`). The memory sweep (`deleteIdleThreads`, `@Memory({ ttl })`) empties an idle thread, leaving an owned one as a tombstone (`isSwept`) only its owner restarts; summaries name their `memory`.
